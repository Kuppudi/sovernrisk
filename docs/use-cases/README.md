# SovereignRisk AI Use Case Dossier

This folder captures five advanced real-world use cases aligned with the current SovereignRisk AI product direction.

Each use case document includes:
- Summary and debt relevance
- Beneficiaries
- Why the use case matters
- Core issue being solved
- How the product simplifies the issue
- Detailed workflow and key capabilities
- Services to provide to users
- Technical stack and intended libraries
- Data and integration requirements
- Risks, controls, and phased delivery
